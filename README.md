# Pocket

Mobile-first React + TypeScript PWA. TODO lists and Shopping are display-only tiles. Zustand stores setup preferences in IndexedDB; no list functionality yet.

## Develop

Node.js 22 or newer.

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

Production service worker is generated by `npm run build`; use preview to test offline support. First successful online visit caches app shell. Google Fonts are optional; system fonts work offline.

## GitHub Pages

1. Push repository to GitHub with `main` as deployment branch.
2. In repository **Settings → Pages → Build and deployment**, select **GitHub Actions**.
3. Push to `main`, or manually run **Deploy to GitHub Pages** workflow.

Workflow sets repository base path automatically, including root `*.github.io` repositories. For custom domains, change workflow `BASE_PATH` to `/`.

Test repository-path builds locally:

```sh
BASE_PATH=/pocket/ npm run build
npm run preview
# Open http://localhost:4173/pocket/
```

## iPhone setup

Open deployed HTTPS URL in Safari. Tap **Share → Add to Home Screen** (enable Open as Web App if offered). Launch Pocket from Home Screen. iOS 16.4+ supports notification permission from installed Home Screen apps. Tap **Enable** in setup; iOS requires direct user interaction. Settings reopens setup after dismissal.

Persistent storage is requested on launch via `navigator.storage.persist()`. Browser decides whether to grant it, often without a prompt. App displays current outcome and offers retry. IndexedDB works without persistent-storage permission, but browser may evict best-effort data. Clearing website data, deleting app, or device policies can remove saved state. No backup or sync exists.

## Notifications

Built in: permission UI, test notification via service worker, push event handler, and notification click handling. Denied permission must be changed in system/browser settings.

GitHub Pages cannot send push messages or schedule reliable background reminders. Background delivery requires external Web Push service/backend. No sender or subscription registration is configured. To add delivery:

1. Obtain public VAPID key from your push sender.
2. From explicit user gesture, call `registration.pushManager.subscribe({ userVisibleOnly: true, applicationServerKey })` after permission is granted.
3. Send resulting subscription to your backend; keep VAPID private key off client and GitHub Pages.
4. Send JSON payload `{ "title": "Pocket", "body": "Your reminder" }` through Web Push. Worker displays it and opens app on tap.

## Verify on device

- Launch installed app; confirm setup and persistent-storage status.
- Dismiss setup, close/relaunch; confirm dismissal survives via IndexedDB.
- Reopen Settings, enable notifications, send test; confirm notification appears (device Focus settings may suppress alerts).
- After first online load, close app, enable airplane mode, relaunch; confirm tiles load.
- Test GitHub Pages repository URL; confirm icons, manifest, scripts, and offline navigation use correct subpath.
